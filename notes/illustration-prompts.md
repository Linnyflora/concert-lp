# 挿絵プロンプト集｜連載「ピアノの先生になるまで」全3回

画像生成AI（ChatGPT／Gemini／Midjourney など）に貼り付けて使うプロンプト集です。
3回とも同じ「共通スタイル」を先頭につけると、シリーズとして絵柄がそろいます。

---

## 0. 共通スタイル（毎回この文を先頭にコピペ）

```
やわらかい水彩と色鉛筆で描いた、あたたかい日本の絵本のような挿絵。
淡いクリーム色の紙の質感、やさしい自然光、彩度を抑えたくすんだ色づかい。
輪郭線は細く、余白を多めに。人物の顔は描き込まず、後ろ姿・横顔・手元で表現する。
色は クリーム(#faf3ec)、くすんだローズ(#b97b74)、真鍮色(#93702f)、濃紺(#262e40) を基調に。
画面には文字・ロゴ・数字を一切入れないこと。写真ではなくイラストで。
```

**注意点**

- 「文字を入れない」は必ず毎回指定してください（AIは日本語の文字が崩れます）
- 手の指や楽譜の音符は崩れやすいので、**手元アップより引きの構図**が安全です
- 実在の先生・ご家族に似せる必要はありません。象徴的な後ろ姿で十分です
- noteのヘッダー画像は **横長（1280×670px前後・アスペクト比 16:9）** が収まりよく表示されます

## 使い方のコツ

1. まず**第1回のヘッダー画像**を生成し、気に入った1枚を決めます
2. 2回目以降は「**この絵と同じタッチで**」と伝えて、その画像を添付すると絵柄がそろいます
3. できあがった画像に文字が入ってしまったら、「文字を消して」と追加で指示してください
4. noteでは、ヘッダー画像1枚＋本文中に1〜2枚あれば十分読みやすくなります
