# 領収書の自動生成スクリプト

Googleフォームの回答から領収書（Googleドキュメント）を自動で作るスクリプトです。
チラシと同じ線画イラストが入るように作り直しました。

- `receipt.gs` … 本体のコード
- `receipt-images.gs` … 領収書に入れるイラストの画像データ（PNGをbase64にしたもの）

イラストは Drive 上のファイルではなくスクリプトの中に埋め込んであるので、
画像ファイルを間違って消してしまっても領収書は作れます。

## 反映のしかた

対象のスクリプト：Googleドライブの「領収書自動生成_1曲ひいてみようコンサート」

1. スクリプトを開き、`コード.gs` の中身をぜんぶ消して、`receipt.gs` の中身を貼り付ける
2. 左の「ファイル」の＋から「スクリプト」を追加し、名前を `画像データ` にして、
   `receipt-images.gs` の中身を貼り付ける
3. 保存する
4. 上部の関数選択で `regenerateAllReceiptsFixedLayout` を選び、「実行」を押す
   - 既に作ってあった領収書（当日日付版・作成日版の両方）はゴミ箱に移動し、
     新しいデザインで作り直します。スプレッドシートのURL欄も新しいものに書き換わります
5. 実行後、`regenerateAllReceiptsFixedLayout` は消してしまって構いません

これ以降にフォームから申し込みがあった分は、これまでどおり
`onFormSubmit` が新しいデザインの領収書を自動で作ります（宛名も自動で入ります）。

## 中身のメモ

- 宛名：フォームの「領収書の宛名」＋「様」。空欄なら「上様」
  - 宛名が姓だけ（例：住田）でも、保護者様・生徒様のお名前と姓が一致すれば
    フルネーム（例：住田未来）にして出します（`resolveReceiptName`）
  - 会社名など、どちらにも当てはまらない場合は書かれたとおりに出します
- 発行日：`EVENT_DATE`（コンサート当日）か、`generateReceiptsWithTodayDate` を
  使った場合は実行した日
- 金額まわり（¥8,000＋消費税¥800＝¥8,800）と発行者情報は `buildReceiptDoc` の中
- イラストの大きさは `HEADER_IMAGE_WIDTH` などの定数で調整できます
